# Assets

Drop your real files in here using these exact names and the site will pick
them up automatically (the layout already has graceful placeholders if a
file is missing):

| File                          | Used for                                  |
|-------------------------------|--------------------------------------------|
| `groom.jpg`                   | Merlito's portrait in the Couple section   |
| `bride.jpg`                   | Daisa's portrait in the Couple section     |
| `gallery-1.jpg` … `gallery-6.jpg` | Photo Gallery grid (jpg or png)        |
| `romantic-instrumental.mp3`   | Floating music player background track    |

Recommended sizes: portraits ~800×800px (square, will be cropped to a
circle), gallery images ~1600px on the long edge. Keep total page weight
reasonable — compress JPEGs to ~150–300KB each for fast loading.
